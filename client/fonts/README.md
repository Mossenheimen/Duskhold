# Fonts

The GUI's type (`VISUALS.md` §8). Both families are under the SIL Open Font License 1.1: the licence
of each is beside it.

| File | Family | From | Used for |
|---|---|---|---|
| `AlegreyaSans-Regular.ttf` | Alegreya Sans, Regular | Google Fonts, `ofl/alegreyasans` | everything in the GUI: the project's default font (`project.godot`, `gui/theme/custom_font`) |
| `AlegreyaSans-Medium.ttf` | Alegreya Sans, Medium | Google Fonts, `ofl/alegreyasans` | headings and banners (`Look.sized`) |
| `Alegreya-Variable.ttf` | Alegreya, variable weight (`Alegreya[wght].ttf`) | Google Fonts, `ofl/alegreya` | titles until 2026-11-17 (now Cinzel's) |
| `AlegreyaSC-Medium.ttf`, `AlegreyaSC-Bold.ttf` | Alegreya SC, the small capitals | Google Fonts, `ofl/alegreyasc` | headings and banners, in gold (`Look.sized`; since 2026-11-17) |
| `Cinzel-Variable.ttf` | Cinzel, variable weight (`Cinzel[wght].ttf`), drawn at 600 | Google Fonts, `ofl/cinzel` | titles: the class choice, the death screen, the menu, the settings (since 2026-11-17) |

Upstream: Huerta Tipográfica (https://github.com/huertatipografica/Alegreya-Sans and
https://github.com/huertatipografica/Alegreya), and The Cinzel Project Authors
(https://github.com/NDISCOVER/Cinzel). Alegreya SC and Cinzel were downloaded 2026-11-17 from
https://github.com/google/fonts (`OFL-AlegreyaSC.txt`, `OFL-Cinzel.txt`); Cinzel is renamed from
`Cinzel[wght].ttf`, the font itself unchanged. Downloaded 2026-11-12 from
https://github.com/google/fonts. The variable serif is renamed from `Alegreya[wght].ttf` (brackets
make awkward paths); the font itself is unchanged.
