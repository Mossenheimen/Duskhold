# Fonts

The GUI's type (`VISUALS.md` §8). Both families are under the SIL Open Font License 1.1: the licence
of each is beside it.

| File | Family | From | Used for |
|---|---|---|---|
| `AlegreyaSans-Regular.ttf` | Alegreya Sans, Regular | Google Fonts, `ofl/alegreyasans` | everything in the GUI: the project's default font (`project.godot`, `gui/theme/custom_font`) |
| `AlegreyaSans-Medium.ttf` | Alegreya Sans, Medium | Google Fonts, `ofl/alegreyasans` | headings and banners (`Look.sized`) |
| `Alegreya-Variable.ttf` | Alegreya, variable weight (`Alegreya[wght].ttf`) | Google Fonts, `ofl/alegreya` | titles only: the class choice, the death screen |

Upstream: Huerta Tipográfica (https://github.com/huertatipografica/Alegreya-Sans and
https://github.com/huertatipografica/Alegreya). Downloaded 2026-11-12 from
https://github.com/google/fonts. The variable serif is renamed from `Alegreya[wght].ttf` (brackets
make awkward paths); the font itself is unchanged.
